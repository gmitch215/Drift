VERIFICATION

This package downloads the Windows installer from the project's GitHub release and checks it
against the SHA-256 value written in tools\chocolateyInstall.ps1. It contains no binary itself.

Installer: https://github.com/gmitch215/Drift/releases/download/v@version@/drift-@version@-windows-x64.msi
SHA-256:   @sha256:windows-x64.msi@

To verify the installer by hand:

1. Download the installer from the URL above.
2. Run `Get-FileHash -Algorithm SHA256 drift-@version@-windows-x64.msi` in PowerShell, or
   `certutil -hashfile drift-@version@-windows-x64.msi SHA256` in cmd.
3. Compare the result with the SHA-256 above and with the line for the installer in the SHA256SUMS
   file attached to the same release:
   https://github.com/gmitch215/Drift/releases/download/v@version@/SHA256SUMS

The release assets carry build provenance attestations. With the GitHub CLI installed,
`gh attestation verify drift-@version@-windows-x64.msi --repo gmitch215/Drift` checks the installer
against the workflow run that built it.

The installer is not code signed.
