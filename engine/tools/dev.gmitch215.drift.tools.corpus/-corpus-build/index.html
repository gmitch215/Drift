CorpusBuild

class CorpusBuild(manifest: CorpusManifest, source: PageSource, work: Path, log: (String) -> Unit = {}, pause: (Long) -> Unit = { Thread.sleep(it) })(source)

Builds the triage corpus. Each repo is paged newest first into <work>/<owner>__<name>.jsonl (already redacted, one canonical JSON issue per line) with a .state file beside it, so a stopped run resumes at the last whole page. assemble sorts everything into one file whose bytes depend only on those lines.
