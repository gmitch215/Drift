StudioState

data class StudioState(val facts: Facts, val changed: DiffResult, val relevant: List<Candidate>, val competing: List<Candidate>, val bundles: List<Bundle>, val unattached: List<RuleMatch>)(source)

The funnel from everything known to the explanations still open: StudioState.facts narrow to StudioState.changed, to the ranked StudioState.relevant candidates, to those StudioState.competing at the top tier (empty unless two or more share it). StudioState.bundles lists the candidates the data cannot separate and StudioState.unattached the rule matches that touch no changed attribute.
