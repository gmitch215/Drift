data class Evidence(val input: List<Run>, val runs: List<RunEvidence>, val excluded: List<Exclusion>, val universe: Int)

data class GreenToRedResult(val green: String, val red: String, val kind: TransitionKind, val changes: List<AttributeDiff>, val ignored: List<AttributeDiff>, val probes: List<ProbeChange>, val steps: List<StepChange>, val background: Int)

What changed between the last green and the first red. GreenToRedResult.changes are static attribute diffs, GreenToRedResult.ignored volatile ones, GreenToRedResult.probes probes that differ, GreenToRedResult.steps steps added or removed from the job; GreenToRedResult.background counts attributes present in either capsule that did not change.

History

data class History(val key: HistoryKey, val runs: List<Run>)

The runs of one History.key, oldest first. A Run has no timestamp, so RunOrder.GIVEN trusts the importer; RunOrder.RUN_ID is for GitHub, whose run ids only grow (a re-run keeps its id).

HistoryState

enum HistoryState : Enum<HistoryState>

What the shape of a history says, over its decisive runs (pass or fail; cancelled and unknown runs say nothing). FLAKY is two or more outcome flips, so a red that recovers is flaky.

data class RunEvidence(val runId: String, val failing: Boolean, val attributes: Int, val coverage: Long)

What one included run contributes: RunEvidence.attributes distinct static paths, and RunEvidence.coverage that count over Evidence.universe in micro-units (1_000_000 is every path any run saw).
