Session

class Session(val report: String, val asks: List<SessionAsk>, val elsewhere: Boolean = false)(source)

What drift why knows between two runs: the report text (redacted), the checks it asked for and the facts each reply gave. The reply text itself is never kept, only the facts read from it. It is written to PATH whenever drift why asks.
