TriageResult

data class TriageResult(val body: String, val author: String?, val truncated: Boolean, val facts: List<Fact>, val rules: List<RuleHit>, val claims: List<ClaimHit>, val draft: DraftRule?, val notEnvironment: NotEnvironment? = null, val ask: List<Ask> = emptyList())(source)

Everything drift triage found in one issue body. body is the SHA-256 of the redacted text and author the hashed login; neither the text nor a login is kept. truncated is true when the body was longer than Triage.MAX_BODY.
