Calibrate
Link copied to clipboard
object Calibrate

Recalibrates the starting confidence of each path on a team's own corpus. Issue bodies that are issue-form output (### Label sections) state their environment under labelled headings; those section facts are the truth, the sections are cut out, and the extractor reads what is left. A path's base is scaled by its accuracy over its mean confidence on the dev side of a seeded split, and the held-out side scores the result.

data class DraftRule(val id: String, val disposition: Disposition, val confidence: Confidence, val key: String, val yaml: String, val notes: List<String>, val rule: Rule? = null)

A rule suggested by the report. yaml is the rule file text in the schema of rules/; a Disposition.DRAFT carries status: draft, which is not a rule status, so it cannot load into the catalog by accident. confidence is the weakest of the two version facts and the symptom signature the rule is built from. notes says why a draft was not published, and rule is the rule to store when it was.

Grade
Link copied to clipboard
enum Grade : Enum<Grade>

How far a rule's detect tree holds on the stated facts. MATCH: every condition holds on facts the issue states. FAILING_SIDE: every condition on the failing side holds and the passing side is not stated, reported only with the rule's symptom text in the issue. SYMPTOM: the failing-side conditions that can be checked hold, some are not stated, and the issue carries the rule's symptom text.

data class RuleHit(val ruleId: String, val title: String, val grade: Grade, val tier: Tier?, val severity: Severity, val status: Status, val confidence: Confidence, val facts: List<String>, val symptoms: List<String>, val mechanism: String)

A rule that applies to the report. tier is the ranker's known for a rule whose symptoms are all verified and plausible otherwise, and only a Grade.MATCH has one: the other grades lack the two-sided difference a tier describes. confidence is the weakest fact the match rests on, scaled by 0.7 for Grade.SYMPTOM; it is not the chance that the rule is the cause.
