Ask

data class Ask(val family: String, val command: List<String>, val why: String)(source)

A check the report does not answer. family is an attribute family key prefix (tool.node, limits.nofile, os.release), command the fixed command to run where it fails and why what the report leaves out. CAPTURE is the family of the whole-machine capture.
