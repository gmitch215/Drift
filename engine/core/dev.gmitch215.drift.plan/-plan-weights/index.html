PlanWeights

object PlanWeights(source)

Every number the planner chooses by hand, in one place, like the ranker's weights: reasoned guesses, not calibrated. They rank experiments against each other; a cost point is not money and an information gain from an uncalibrated prior is not a measured quantity.
