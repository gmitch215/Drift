core/dev.gmitch215.drift.plan/Options

Options

data class Options(val trialMinutes: Long, val failures: Int, val runs: Int, val alpha: Long = PlanWeights.ALPHA, val power: Long = PlanWeights.POWER, val maxPerArm: Int = Trials.MAX_PER_ARM, val unknown: Long = PlanWeights.UNKNOWN_PRIOR, val couplings: Map<String, String> = COUPLINGS)(source)

Per-run inputs. Options.failures of Options.runs is the observed failure rate of the red side; Options.trialMinutes is the wall time of one trial of the failing command. Options.couplings maps an attribute to the hypothesis it always moves with, for one change that shows as several. A target step:NAME without a job names the first added step called NAME. The default merges the provisioner build date with its version and the Node and npm versions with Set up Node.
