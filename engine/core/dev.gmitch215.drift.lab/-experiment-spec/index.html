ExperimentSpec

class ExperimentSpec(source)

Everything 6d3 needs to run one experiment, and everything a reader needs to check it was decided in advance: the arms with their interventions and file hashes, the predicted diff and the verdict it allows, the trials, and the rule with its hash. It holds no result, runs nothing and touches no network. A manual experiment is the same file with no runnable arms and the printed ExperimentSpec.instructions. executable is false unless every member can be set and the budget reaches significance.
