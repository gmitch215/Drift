SolveVerdict

data class SolveVerdict(val kind: VerdictKind, val why: StuckWhy?, val statement: String, val set: List<String> = emptyList(), val members: List<String> = emptyList(), val notIsolated: List<String> = emptyList(), val mechanism: String? = null, val candidates: List<String> = emptyList(), val next: String? = null)(source)

The outcome of a solve. SolveVerdict.set is the minimal causal set (hypothesis ids), SolveVerdict.members the attributes the arms differ in, SolveVerdict.notIsolated the members of a bundle that no arm has pulled apart; SolveVerdict.candidates and SolveVerdict.next are for NARROWED.
