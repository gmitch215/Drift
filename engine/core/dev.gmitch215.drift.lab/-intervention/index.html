Intervention

sealed class Intervention(source)

A typed change to one run configuration. Applying it edits the capsule the container is synthesized from, so the Dockerfile, the run.sh flags and the manifest all follow from the same code as reproduce. The attributes it changes are recorded by the edit, not declared by hand. Every value is the capsule's own spelling (120000 100000 for a cpu limit).
