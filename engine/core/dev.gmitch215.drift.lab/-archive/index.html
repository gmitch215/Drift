Archive

object Archive(source)

The .driftcase file: a deterministic tar of a solved case directory. The arm folders move from arms/ to reproduce/, confirmed/minimal-set.json records the minimal causal set when the verdict is a CONFIRMED one, report.html is generated from the certificate, and the manifest is rebuilt over what the archive holds.
