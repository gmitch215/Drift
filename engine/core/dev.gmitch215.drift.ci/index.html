data class CapsuleDirectory(val capsule: Capsule, val run: Run? = null, val execution: Execution? = null, val tail: String? = null)

A directory holding one environment: capsule.json, and when known run.json (the Run with its outcome, steps and symptoms) and result.json (an Execution, written by drift run). tail.log holds the bounded log tail and is never read back.

GithubImport

object GithubImport

Reads GitHub Actions output that was saved to a file: a job log (raw, or as printed by gh run view --log) and the summary from gh run view --json. The runner image block, the operating system group, the runner version and the job env: block become capsule attributes with source log; symptoms come from SymptomExtractor.

object GitlabImport

Reads GitLab CI output that was saved to a file: a job trace and the pipeline JSON (the pipeline object, an object with a jobs array, or the jobs array alone). The runner version, executor and image in the trace become capsule attributes with source trace.
