UpgradeItem

class UpgradeItem(val scenario: String, val template: String, val move: String, val downgrade: Boolean, val input: Capsule, val target: Target, val signature: String, val explained: Boolean)(source)

One move of a migration scenario. A break item takes the passing arm's capsule and moves its cause attribute to the failing arm's value, so the measured red arm is the truth. A control item takes the failing arm's capsule and moves to the passing value: the green arm passed every trial, so nothing breaks. downgrade is true when the target is older than the capsule.
