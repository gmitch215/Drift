class DockerExecutor(host: Host, workspace: String, driftBinary: String? = null, timeoutSeconds: Long = 120, maxMemory: String? = null, maxCpus: String? = null) : Executor

Runs arms with docker through the host's process runner. Each trial is one docker run --rm with the flags reproduce derived from the capsule; output is cut to its last OUTPUT_BYTES bytes and one trial is cut off after timeoutSeconds. maxMemory and maxCpus apply only to an arm whose capsule sets no limit of its own.
