Classification

documented, basis verified; causes: documented difference.

Occurrences of ${name} or $index in the replacement string will be substituted

https://kotlinlang.org/api/core/kotlin-stdlib/kotlin.text/-regex/replace.html

Notes

Identical on every column of fixtures/atlas at 2.4.20 and of fixtures/atlas-extra. Probe notes: Identical on every column measured. The replace page (read) documents dollar-index and dollar-brace-name group references in the replacement; the other lines have no page read.

Read on 2026-10-07.

Kotlin versions measured

2.4.20, 2.5.0-Beta1

How it was measured

  • android: The androidApp debug build on an arm64 Android emulator (Pixel 7 profile, API 37), started with an intent that writes the transcript.
  • ios: The iosApp simulator build on an iPhone 17 Pro simulator (iOS 26.5, arm64), started with an environment variable that writes the transcript.
  • jvm: The CLI JVM build on Temurin 21 on macOS, Apple Silicon (arm64). Recorded with drift atlas record.
  • jvm-17: The CLI JVM classes (jvmTarget 17) on Temurin 17.0.20.1, x86-64 Linux container, recorded with --target jvm-17.
  • jvm-21: The same classes on Temurin 21.0.12.1, x86-64 Linux container. Differs from the jvm column in hardware only.
  • jvm-25: The same classes on Temurin 25.0.4.1, x86-64 Linux container.
  • linux: The Kotlin/Native linuxX64 release executable, cross-linked on macOS, run in a debian:bookworm-slim container (glibc 2.36), x86-64. The same executable on ubuntu:24.04 (glibc 2.39) recorded identical results, kept in fixtures/atlas-extra. A release executable linked on macOS prints Apple libm values for three math constants (tan1, asin-half and acos-half); one linked on Ubuntu, or a debug build, prints glibc values. The Ubuntu-linked transcript is in fixtures/atlas-variants.
  • linux-arm64: The Kotlin/Native linuxArm64 release executable, cross-linked on macOS and run in an arm64 debian:bookworm-slim container. The Ubuntu-linked transcript, which differs on the same three math lines, is in fixtures/atlas-variants.
  • macos: The Kotlin/Native macosArm64 executable on macOS, Apple Silicon (arm64). Recorded with drift atlas record.
  • wasm: Kotlin/Wasm (wasmJs) on Node 26.8.2, macOS, Apple Silicon. Recorded through the wasm test harness because the wasm CLI has no file writer.
  • wasm-chromium: The Studio web build in Chromium 153.0.8010.12 (V8), driven by Playwright 1.63.0 on x86-64 Linux in a container.
  • wasm-firefox: The Studio web build in Firefox 155.0 (SpiderMonkey), driven by Playwright 1.63.0 on x86-64 Linux in a container.
  • wasm-webkit: The Studio web build in WebKit 26.6 (JavaScriptCore, the Playwright build for Linux), driven by Playwright 1.63.0 on x86-64 Linux in a container. Not Safari.

Results are recorded measurements for the listed Kotlin versions. A difference between targets is a result, not a diagnosis.
