What is known: Downgraded from documented: cloudflare-jvm prints 5.0 for 5%0.0 where every other column prints NaN. The JLS (15.17.3) gives NaN for a zero divisor and the Kotlin Double.rem page says the result is less than the divisor in absolute value, so the TeaVM result breaks both; no TeaVM issue was found and the TeaVM code was not read. js-ir differs only in text: -0.0%5 prints 0 and 5%inf prints 5 (KT-21235 Open is the js and jvm Double.toString difference). The integer lines agree on every column. cloudflare-wasm prints what wasm prints.
