# Module Drift Engine Documentation

Reference documentation for the engine and tools inside the Drift application. It describes how the code is organized so the source is easier to read. Drift ships as an application, and these modules are not published artifacts.

The modules are `core`, `host`, `scan`, `tools`, `bench`, `cli` and `studio`. The `build-core` Gradle build logic, the Android application module and the Xcode project are not documented here.
